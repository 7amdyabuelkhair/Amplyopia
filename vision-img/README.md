# Vision Test Image Assets

Place your PNG files in this folder using the exact filenames below.
The vision test page loads different images based on the signed-in child's gender:

| Gender | Theme |
|--------|-------|
| Unknown / guest | Yellow |
| Boy | Blue |
| Girl | Pink |

---

| Filename | Used for |

| `cloud.png` | Background cloud decorations |

## Tips

- Use **PNG** with transparent backgrounds where possible.
- Recommended size for corner characters: about **280–360 px** tall.
- Recommended size for icons in info cards: about **48–64 px**.
- Recommended size for arrow buttons: about **40–56 px**.

If a file is missing, the page still works — broken images are hidden automatically.
